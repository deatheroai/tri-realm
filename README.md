# tri-realm

tri-realm is a foundational game engine for building explorable, buildable worlds across three environments: land, air, and sea. It provides the core systems for avatar navigation, map traversal, and player-driven construction (starting with castles), designed to scale across all three realms as a unified movement and building framework.

## Goals

- Unified avatar controller that adapts to terrain, flight, and water navigation
- A shared map/world representation that supports all three realm types
- Player-driven building/construction system (castles, structures) placeable across realms
- Modular architecture so new realms, movement types, or building mechanics can be added later
